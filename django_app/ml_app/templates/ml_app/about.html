Project Overview

About NeuroScan ASD

An end-to-end machine learning web application for screening Autism Spectrum Disorder (ASD) indicators in children, built with Django, scikit-learn, and a modern research pipeline.

The Dataset

The dataset is sourced from the University of Arkansas Computer Science Department as part of autism research. It contains clinical and behavioral measurements for children, including the AQ-10 Autism Spectrum Quotient, Q-CHAT-10 score, Childhood Autism Rating Scale (CARS), demographic information, and a range of co-occurring conditions such as speech delay, learning disorders, genetic disorders, and anxiety.

ML Pipeline

The machine learning pipeline consists of four stages documented in Jupyter notebooks:

  1. Exploratory Data Analysis (01_eda.ipynb) — Understanding distributions, missing values, class balance, and correlations.
  2. Preprocessing (02_preprocessing.ipynb) — Label encoding, standard scaling, and feature engineering.
  3. Modeling (03_modeling.ipynb) — Training Logistic Regression, Decision Tree, Random Forest, KNN, and SVM.
  4. Evaluation (04_evaluation.ipynb) — Comparing accuracy, F1, precision, recall, and confusion matrices.
Best Model: Random Forest

After evaluating all five classifiers, Random Forest was selected as the production model with 97% accuracy on the held-out test set. It offers the best trade-off between precision and recall, handles both numerical and categorical features robustly, provides feature importance scores, and is resistant to overfitting via ensemble averaging.
